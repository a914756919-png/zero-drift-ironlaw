# 🔴 强制零漂移铁律 v2.6

> 让你的 AI 助手再也不跑偏、不撒谎、不泄密、不空转。

## 这个 Skill 解决什么

用过 AI 编程助手的人，几乎都遇到过这些"顽疾"：

- **漂移**：让你做 A，它做着做着变成 A+B+C，最后交付的东西和你要的"天差地别"
- **撒谎**：说"已完成""已验证"，实际没做没跑
- **泄密**：把 API key、绝对路径、手机号原样写进代码/文档
- **空转**：同一个失败动作反复重试，撞墙 10 次还不换策略

本 Skill 用一套强制反思体系（R1-R10）把这些问题全部锁死。每次交付前，AI 必须完成七步反思 + 严格忠实校验 + 通用纪律校验，输出带"开头执行声明 + 末尾反思摘要"的合格交付。

## 核心能力

| 维度 | 内容 |
|------|------|
| 防漂移 | R9 通用纪律校验：重述要求→一对一映射→抑制顺手冲动→连续失败警告→工具一致性→工具失控→最终一致性，7 步前置自检 |
| 防撒谎 | R8 严格忠实原则：禁止撒谎/偷懒/漂移/自作主张，漂移检测三问 |
| 防泄密 | 核心规则 12 隐私脱敏：交付前扫描 key/凭证/路径/PII，发现即脱敏 |
| 防空转 | 核心规则 13 工具失控检测 + R9 Step 7：同一方法失败 2 次必须换策略 |
| 防自嗨 | 用户锚定原则：用户指定方向是唯一事实源，存疑即停，未经确认不做选择 |

## 快速开始（30 秒）

**关键认知**：要让"任何新项目、任何新对话"都被把关，必须把铁律装进平台的**全局指令层**（不是项目级），这样每个新会话都会自动带上它。

### Windows（一键安装）

1. 从 Gumroad 付款后下载 zip，解压
2. **双击 `install.bat`**
3. 脚本自动检测 TRAE / Claude Code / Cursor，写入各自全局位置，弹出介绍文案窗口
4. 新建对话测试：让 AI 写点东西，看它是否输出"铁律执行声明 + 反思摘要"——看到即生效

### macOS / Linux（一键安装）

1. 付款后打开终端，执行一行命令：

   ```bash
   curl -fsSL https://raw.githubusercontent.com/a914756919-png/zero-drift-ironlaw/main/install.sh | bash
   ```

2. 脚本自动下载并配置 TRAE / Claude Code / Cursor 的全局位置
3. 新建对话测试，看到"铁律执行声明"即生效

### 网页平台（ChatGPT 网页版 / DeepSeek / 通义等）

不支持脚本的平台：手动把 `SKILL.md` 全文粘贴到"自定义指令 / Custom Instructions"即可（可省略版本历史章节）。

## 安装后效果

- 每个新项目、每个新对话，AI 都会先执行 R9 前置自检再动手
- 每次回复开头带铁律执行声明，末尾带反思摘要
- 发现 AI 跑偏、撒谎、泄密、空转时，你有明确的判据和红线去质询

## 注意事项

- 铁律强度依赖你把它装进**全局**配置：只装进单个项目的话，仅该项目生效
- 各平台全局配置的具体路径以该平台最新文档为准（安装器已标注常见位置）
- 铁律是"行为规则"，不包含任何用户个人数据，可安全分发
- 一键安装器仅写入本机全局配置目录，不收集、不上传任何数据
